# Decisions

Choices made where SPEC.md was silent or ambiguous. Newest last.

| Date       | Milestone | Decision                                                                                                                                                                                                                                                 | Why                                                                                                                                                                                                        |
| ---------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-13 | M0        | `npm run lint` builds `@kloister/shared` before running ESLint.                                                                                                                                                                                          | Type-aware lint rules resolve `@kloister/shared` through its compiled `dist/` declarations; without this, lint fails on a clean checkout when run before `build` (the order local verification runs them). |
| 2026-10-13 | M0        | CI skips runs for `**.md` and `docs/**` changes.                                                                                                                                                                                                         | Keep CI usage minimal; docs cannot break the build.                                                                                                                                                        |
| 2026-10-13 | M0        | `apps/api` sets `strictPropertyInitialization: false`; all other `strict` checks stay on.                                                                                                                                                                | Nest DTOs and injected properties are populated by class-validator/DI, not constructors; this is the standard Nest setting.                                                                                |
| 2026-10-13 | M0        | Backend reads `BACKEND_HOST` (default `127.0.0.1`) alongside `BACKEND_PORT` (default `3000`).                                                                                                                                                            | Keeps the API off public interfaces behind httpd by default (SPEC §9.4 proxies to `127.0.0.1`); the host is configurable rather than hard-coded.                                                           |
| 2026-10-13 | M0        | Native ESM throughout; Jest runs with `--experimental-vm-modules`. TypeScript 6.0, Node 24 (`.nvmrc`).                                                                                                                                                   | Current majors at scaffold time. Node 24 is Active LTS now; revisit `.nvmrc` when Node 26 becomes Active LTS.                                                                                              |
| 2026-10-13 | M0        | ESLint requires a described doc comment with `@param`/`@returns` on exported symbols, and has no auto-fixer for it.                                                                                                                                      | SPEC §11 asks for purpose and parameters; a fixer would insert empty stubs.                                                                                                                                |
| 2026-10-13 | M0        | Stock Angular favicon replaced with a neutral SVG placeholder.                                                                                                                                                                                           | SPEC §1: no third-party or employer branding; the logo is admin-set (M6).                                                                                                                                  |
| 2026-10-13 | M1        | CI also runs on `workflow_dispatch` (manual runs).                                                                                                                                                                                                       | Lets the owner re-run CI on demand without pushing a commit.                                                                                                                                               |
| 2026-10-13 | M1        | Prettier scripts pass `--ignore-path .gitignore --ignore-path .prettierignore --ignore-path .git/info/exclude`.                                                                                                                                          | Local-only files are skipped without being named in tracked config. `--ignore-path` replaces Prettier's defaults, so the first two are listed explicitly.                                                  |
| 2026-10-13 | M1        | Database-backed tests (`npm run test:db -w @kloister/api`) run only in CI, against a Postgres 18 service container pulled from the Amazon ECR Public mirror of the official image. `npm test` runs unit tests and HTTP tests that stop before any query. | No database runs on the development machine; the ECR mirror avoids Docker Hub pull rate limits on Actions.                                                                                                 |
| 2026-10-13 | M1        | Migrations are generated offline with `prisma migrate diff --from-empty`/`--from-migrations`; CI applies them with `migrate deploy` and fails if `prisma migrate diff --exit-code` finds schema drift.                                                   | `migrate dev` needs a live database; the CI check guarantees the committed SQL matches `schema.prisma`.                                                                                                    |
| 2026-10-13 | M1        | Prisma 7.10 (latest stable; npm `latest` points at an 8.0 RC). Client generated into `apps/api/src/generated/` (gitignored) by `build`, `lint` and `test`. `prisma` is a runtime dependency.                                                             | Avoid pre-release majors. Generated code stays out of git. install.sh/upgrade.sh run `prisma migrate deploy` on the server, which `npm ci --omit=dev` must provide.                                        |
| 2026-10-13 | M1        | Per-IP login rate limit is a small in-house guard (default 10 attempts/60s, `LOGIN_RATE_LIMIT`, `LOGIN_RATE_WINDOW_SECONDS`), not `@nestjs/throttler`.                                                                                                   | `@nestjs/throttler` is CommonJS and cannot be loaded next to ESM-only Nest 12 under Jest. A single backend process makes in-memory counters sufficient.                                                    |
| 2026-10-13 | M1        | Fastify `trustProxy` comes from `TRUST_PROXY` (default `loopback`; `false` disables). Rate limiting and session IPs use `request.ip`.                                                                                                                    | httpd proxies from the same host (SPEC §9.4), so only loopback may set `X-Forwarded-For`; others cannot spoof their address.                                                                               |
| 2026-10-13 | M1        | Session cookie is named `sid`; its `Path` is `/<APP_NAME>/` from the `APP_NAME` env var, or `/` when unset (local development).                                                                                                                          | SPEC §5 fixes the path; the name stays neutral (no product name). The app name is deployment config, not code.                                                                                             |
| 2026-10-13 | M1        | Users with `mustChangePassword` can only call `GET /me`, `POST /auth/logout` and `POST /auth/change-password`; everything else returns 403 `PASSWORD_CHANGE_REQUIRED`.                                                                                   | SPEC §5 forces the change; enforcing it in the API (SPEC §3.4) means the UI cannot be bypassed.                                                                                                            |
| 2026-10-13 | M1        | The last active admin cannot be demoted or deactivated (409 `LAST_ADMIN`), checked in a serializable transaction.                                                                                                                                        | Mirrors the last-PM rule (SPEC §3.2); the system must never lose all administrators.                                                                                                                       |
| 2026-10-13 | M1        | Admins reset other users' passwords only; their own goes through change-password.                                                                                                                                                                        | A self-reset would sign the admin out with a password they must immediately change.                                                                                                                        |
| 2026-10-13 | M1        | Every login failure (unknown email, deactivated, locked, wrong password) returns the same 401 `INVALID_CREDENTIALS`; unknown emails still run an argon2 verify.                                                                                          | Responses and timing do not reveal which accounts exist or are locked. The audit log records the real reason.                                                                                              |
| 2026-10-13 | M1        | A wrong current password on change-password returns 400 `INVALID_CREDENTIALS`, not 401.                                                                                                                                                                  | A 401 means "signed out" to the web app; the user is still signed in.                                                                                                                                      |
| 2026-10-13 | M1        | Session/lockout settings are read from `AppSetting` key `security` with SPEC defaults; invalid stored values fall back to defaults. `lastSeenAt` is refreshed at most once a minute.                                                                     | Admin editing arrives in M6. Bad rows can never disable lockout. Avoids a write on every request.                                                                                                          |
| 2026-10-13 | M1        | Admin bootstrap is `node dist/cli/create-admin.js --email … --name …`; it does nothing if an active admin exists, and prints the temporary password once to stdout.                                                                                      | SPEC §9.4 step 10 and the idempotency rule in §9.3.                                                                                                                                                        |
| 2026-10-13 | M1        | Emails are validated without requiring a TLD.                                                                                                                                                                                                            | Internal mail domains (e.g. `user@intranet`) are common in the target environments.                                                                                                                        |
| 2026-10-13 | M1        | M1 includes the login, change-password, admin users and audit log screens. The UI uses system fonts and no icon fonts.                                                                                                                                   | SPEC §6 lists them and M1 delivers their API. The server may have no internet access, so nothing is loaded from external hosts.                                                                            |
| 2026-10-13 | M1        | OpenAPI generation into `docs/` (SPEC §8) is deferred to M7; pino with daily-rotated files (SPEC §2) is deferred to M6. Nest's built-in logger is used until then.                                                                                       | OpenAPI output ships with the release docs (M7). Log rotation and retention are configured together in M6 (admin log retention).                                                                           |
| 2026-10-13 | M1        | `APP_NAME` is required when `NODE_ENV=production`; the backend refuses to start without it.                                                                                                                                                              | Keeps the SPEC §5 cookie path from silently widening to `/` on a misconfigured server.                                                                                                                     |
| 2026-10-13 | M1        | Change-password shares the per-IP login rate limit, and wrong current passwords are audited (`PASSWORD_CHANGE_FAILED`). Failed logins for unknown accounts record the submitted email only if it looks like an email.                                    | A hijacked session cannot guess the current password quickly or silently. A password typed into the email field never lands in the audit log.                                                              |
| 2026-10-13 | M1        | Serializable-transaction conflicts (Prisma P2034) return 409 `CONFLICT` ("try again"). Explicit `null` in update bodies is rejected with 400.                                                                                                            | Clients get an actionable error instead of a 500.                                                                                                                                                          |
| 2026-10-13 | M1        | The interim UI palette is Material's blue, the closest built-in palette to SPEC §6's indigo.                                                                                                                                                             | Material 3 has no indigo or slate palette; admin theming replaces this in M6.                                                                                                                              |

## Follow-ups for later milestones

- **M2**: write `ADMIN_CROSS_PROJECT_ACCESS` audit entries (SPEC §3.1) when admins read projects they are not members of.
- **M6**: app name comes from admin settings; update `index.html` title and the web test that asserts the literal name. Add admin editing of the `security` setting (session timeouts, lockout). Switch logging to pino with daily-rotated files (SPEC §2).
- **M7**: `@kloister/shared` is a runtime dependency of the API; the release `backend/` must bundle or vendor it, since `npm ci --omit=dev` cannot resolve a private workspace package. Set the production base href to `/__KLOISTER_BASE__/` (SPEC §9.2). Ship `prisma.config.ts`, `prisma/` and migrations in `backend/`; run Prisma commands with `CHECKPOINT_DISABLE=1` so the CLI makes no outbound update check. Confirm the `argon2` prebuilt binary loads on RHEL 8 (else switch to `@node-rs/argon2`, SPEC §2). install.sh passes `APP_NAME` and `DATABASE_URL` via `kloister.env` and runs `create-admin`. Set `NODE_ENV=production` in `kloister.env`. Make sure the `create-admin` temporary password goes to the terminal only and is never copied into `logs/install/` (SPEC §9.4 step 10). Generate the OpenAPI document into `docs/` at build time (SPEC §8).
